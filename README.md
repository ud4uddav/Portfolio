# Uddhav Dhakal — Portfolio

A responsive React portfolio for [ud4uddav.github.io](https://ud4uddav.github.io/), built with Vite and plain CSS. It has no UI library, backend, or third-party assets.


## Deploy to GitHub Pages

GitHub Pages must use **GitHub Actions** as its source. The workflow builds the app and publishes `dist` on each push to `main`. The site is available at `https://ud4uddav.github.io/`.
