# Uddhav Dhakal — Portfolio

A responsive React portfolio for [ud4uddav.github.io](https://ud4uddav.github.io/), built with Vite and plain CSS. It has no UI library, backend, or third-party assets.

## Edit the site

Update project details and skills near the top of `src/main.jsx`. Add verified project repository or demo links only when you have them, and add a public email address if you want an email link.

## Run locally

Install Node.js 20.19+ or 22.12+, then run `npm install` and `npm run dev`. Use `npm run build` to create a production build.

## Deploy to GitHub Pages

The workflow builds the app and publishes `dist` on each push to `main`. GitHub Pages is available at `https://ud4uddav.github.io/`.
