# Uddhav Dhakal — Portfolio

A responsive, static portfolio for [ud4uddav.github.io](https://ud4uddav.github.io/). It uses one HTML file with inline CSS. No framework, dependencies, build step, API, or third-party assets are required.

## Edit the site

Update `public/index.html`. Add verified project repository or demo links only when you have them, and add a public email address if you want an email link. The current project descriptions and skills are editable directly in the HTML.

## Deploy to GitHub Pages

This site is designed for a user-site repository named `ud4uddav.github.io`. Push the contents of this folder to that repository's `main` branch, then set **Settings → Pages → Build and deployment → Source** to **GitHub Actions**. The workflow publishes the `public` folder automatically.
